# 城市包点位覆盖度与坐标核验

> 目的：城市包在**在线模式下也是优先数据源**（`resolve()` 城市包优先），
> 因此包里的错点比"不收录"更糟——它会稳定地把用户带到错误的地方。
> 本文记录每个新收录点位的**两个独立来源**、采用值与营业时间出处，可追溯。

## 一、为什么必须双源

D-36 的教训：早期坐标是手写估算，抽查偏 300–1100 米；而当时的"校验"用的是
「名称检索 + 周边同名搜索」——**用同一个引擎、同一个关键词去印证自己**，
偏差当然是 0，属于循环验证。本文的"来源 B"一律换成**不同机制**：

| 来源 | 机制 | 用途 |
|---|---|---|
| A · place/text | 关键词文本检索（city 限定，`extensions=all`） | 取坐标 + `biz_ext` 营业时间 |
| B · geocode/geo + regeo | 用**地址**反查坐标，再由 `regeo` 的 AOI/名称确认落点 | 独立印证 A，判断是否同一实体 |

判定：A、B 指向同一实体且偏差在可接受范围（点位 ≤ 50 m，道路型 ≤ 300 m）才采纳；
否则标"存疑"交人工，**不写入**。

## 二、第一轮的两个假阳性（反面教材）

工具初版只看"名称包含 + 周边同名偏差 0 m"，于是把下面两个也判成"采纳"：

| 待补 | 工具采纳成 | 为什么错 |
|---|---|---|
| 苜蓿园美食街 | 樟荣沙县小吃苜蓿园大街店 | 一家小吃店；高德根本没有"苜蓿园美食街"这个 POI |
| 颐和路民国公馆区 | 颐和路12号民国建筑 | 单栋建筑，不是整个公馆区 |
| 北京理工大学中关村校区 | 中关村校区**北区** | 校园内的一个片区，不是校区 |

结论：`place/around` 同名检索**不能**作为独立来源。改用「geocode 地址 → regeo 确认」后
全部纠正。

## 五、口径与取舍

* **季节性景区**（植物园、香山、八大处、卧佛寺）高德只给多段字符串，本包按**11 月所在淡季**
  取一对保守值，原始串写进 `book` 字段，界面 `poi_brief` 会一并显示，便于追溯。
* **道路型点位**（苜蓿园大街、模式口大街）没有营业时间，属正常；不要为了"字段齐全"编造时间。
* 别名必须全库唯一，由 `tests/test_city_pack_integrity.py` 守住（含"坐标是否串城""营业时间格式"）。

## 六、可重复验证

```bash
cd code
python -m pytest tests\test_city_pack_integrity.py -q     # 字段完整性（离线）
python -m pytest -m online -q                             # 联网验收（含案例三地点准确率）
```

复跑工具：`tools/calibrate_poi_coords.py`（核对**已有**点位，`--apply` 才写回）。
新增点位的双源候选表可由 `place/text` + `geocode→regeo` 两步复现（见本文判定规则）。

筛选口径（避免“包越大越难看”）：
- 剔除噪声：停车场、公交站、地铁站、售票处、出入口、便利店、药店、超市、外卖柜、储物/更衣区、食堂（片区包保留 3 家校内食堂作为用餐点）、菜场、专卖店；
- 评分门槛：景点 ≥4.3、公园 ≥4.0、商场 ≥4.4、街区 ≥4.0；
- 商场按类别限量 30 条，同商场的 A/B/C 分馆只保留主馆；
- 坐标与营业时间用高德真实值；`visit`（推荐游玩时长）仍是估算，在线时由 `intel` 覆盖。

**在线 vs 离线的边界不变**：在线解析走 `place/text` + `name_alike` 校验（包外地点照样能排）；静态包的作用是**离线可跑**与**推荐候选池**，不是“能力上限”。

补充说明（医疗要素）：高德 `090100` 类型码对关键词较敏感，直接按类型检索常返回空；改用
关键词纯检索（医院/妇幼保健院/中西医结合医院/人民医院/附属医院/战区总医院）并放开评分门槛后取到 27 家，
同时剔除诊所、药房、体检中心、口腔眼科等非就诊目标。
