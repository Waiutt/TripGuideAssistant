---
name: plan_trip
title: 排一份行程草案
when_to_use:
  - 用户想让你排行程、问"推荐哪些景点"、说"没头绪"
  - 用户给了日期、天数或时间窗口，要一版可确认的草案
inputs:
  - 日期或时间窗口（如 11月中旬、11月14号-11月16号）
  - 人数、节奏、几点起床、几点回酒店
  - 点名必去的地点（含"某天要找谁吃饭"这类）
  - 住宿：酒店名，或明确说"你帮我选"
outputs:
  - 按天分的草案：日期、主题、每项地点与耗时、营业时间
  - 为什么这么排的一句话解释
  - 待补地点清单与住宿建议
impl: nanjingtrip.consult:Consultant.build_plan
needs_network: true
fallback: 离线时只用城市包里的建议时长与开放时间，不编造
limits:
  - 模糊窗口不排满："11月中旬"先给 3 天，并说明可以加天
  - 没给住宿时先追问，不擅自替用户定酒店
  - 景点耗时必须来自证据表或高德实测，不许估一个数当实测
---
排草案时先定"哪天玩"，再定"每天玩什么"：先按地理相邻分组避免横跨全城，
再套用户节奏（懒人就 10:00 起排、不赶早场），最后补一顿就近的饭。
"某天要找朋友吃饭"若对方只有周末有空，就把那天整体挪到窗口里的周末，
并在说明里给出具体日期，方便用户去约人。
