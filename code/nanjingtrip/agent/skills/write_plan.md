---
name: write_plan
title: 预览确认后写入当天排程
when_to_use:
  - 用户在草案上点确认，要真正落库
  - 一句话里的多件事要一次写入同一天
inputs:
  - 草案中的按天事项（地点、时长、开始/截止时刻）
  - 住宿锚点、起床与回酒店时刻
outputs:
  - 当天排程（锁定优先 + 空档扫描 + 通行时长 + 缓冲）
  - 溢出、重叠与营业时间冲突提示
impl: nanjingtrip.services:TripService.add_batch
needs_network: true
fallback: 离线时通行时长走本地缓存或按城市包估算，并标注为估算
limits:
  - 写入要逐天排程与取通行时长，通常十几秒，必须当场给进度反馈
  - 排不下就给出取舍建议，不静默丢弃用户点名的项
---
写入是一次事务性动作：要么整天的排程都算完再落库，要么明确告诉用户哪几项没排进去。
